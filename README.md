PlacePilot
A responsive, single-page placement tracking prototype for students. It consolidates opportunities, application statuses, requirements, shortlists, deadlines, and reminders into one dashboard.
Preview locally
Open `dist/index.html` in a browser or serve the folder with any static web server.
Publish with GitHub Pages
Create a GitHub repository and push this project.
In Settings → Pages, select Deploy from a branch.
Select the publishing branch and `/docs`, or use a GitHub Actions workflow to publish `dist`.
This prototype uses realistic sample data. Outlook, WhatsApp, and placement-portal integrations are represented visually but are not connected.
